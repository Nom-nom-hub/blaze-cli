blaze-install

A Node package manager focused on health, diagnostics, and plugins — npm-compatible, with a built-in doctor and 30+ checks.

GitHub Features
npm i -g blaze-install   then   blaze doctor --json

Doctor & health

Auto-fix lockfile drift, missing node_modules, broken symlinks. JSON output for CI.

Plugins

Health score, license checker, dependency-age reporter, size analyzer, monorepo cross-link checker.

Workspaces

Monorepo linking with cross-link validation.

Offline

Prefetch and offline installs from global cache.

Honest speed

pnpm ~3.0s · yarn ~4.9s · npm ~7.1s · blaze ~5.9s on a 7-dep cold install. We compete on health, not raw speed.
